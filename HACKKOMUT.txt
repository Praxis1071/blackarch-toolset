# 2. SecretFinder

## Amaç
JavaScript dosyaları veya web sayfaları içerisinde bulunabilecek hassas verileri,
API anahtarlarını, parolaları ve gizli uç noktaları aramak için kullanılır.

## Temel kullanım
```bash
secretfinder -i file://$PWD/index-BhYj0Brp.js -o cli
```

## Örnekler

### Bir URL'deki JavaScript dosyalarını tarama
```bash
secretfinder -i https://example.com -e
```

### Sonucu HTML dosyasına kaydetme
```bash
secretfinder -i https://example.com/dosya.js -o rapor.html
```

### Burp Suite çıktısını analiz etme
```bash
secretfinder -i burp_raporu.xml -b
```

### Oturum çerezi ile yetkili sayfayı tarama
```bash
secretfinder -i https://example.com/panel -e -c "session=EXAMPLE_SESSION_TOKEN"
```

### Özel HTTP başlıkları ekleme
```bash
secretfinder -i https://example.com -e -H "Authorization: Bearer EXAMPLE_TOKEN\nUser-Agent: Mozilla/5.0"
```

### Yalnızca belirli API yollarını arama
```bash
secretfinder -i https://example.com -e -r "^/api/"
```

### Yerel JavaScript dosyasını inceleme
```bash
secretfinder -i /yol/dosya.js -o sonuc.html
```

### Yerel klasördeki dosyaları inceleme
```bash
secretfinder -i /yol/klasor/ -o cikti.html
```

### İstekleri yerel vekil sunucu üzerinden yönlendirme
```bash
secretfinder -i https://example.com -e -p 127.0.0.1:8080
```

### Belirli kütüphaneleri hariç tutma
```bash
secretfinder -i https://example.com -e -g "jquery;bootstrap;analytics"
```

### Belirli adlara sahip dosyalara odaklanma
```bash
secretfinder -i https://example.com -e -n "app;main;bundle"
```

# 7. Subfinder

## Amaç
Bir alan adının alt alan adlarını pasif kaynaklar üzerinden keşfetmek için kullanılır.
Arama motorları, sertifika şeffaflığı kayıtları ve diğer OSINT kaynaklarından yararlanabilir.
Pasif kaynak kullanımı hedefe doğrudan tarama yapılmadığı anlamına gelir; ancak kullanılan dış kaynaklara sorgu gönderilir.

## Önemli seçenekler

- `-d, -domain` : Alan adını belirtir.
- `-dL, -list` : Birden fazla alan adını içeren dosyayı kullanır.
- `-s, -sources` : Kullanılacak kaynakları sınırlar.
- `-all` : Kullanılabilen tüm kaynakları kullanır.
- `-o, -output` : Sonuçları dosyaya kaydeder.
- `-silent` : Çıktıyı yalnızca bulunan alt alan adlarına indirger.

## Örnekler

### Tek alan adı
```bash
subfinder -d hedefsite.com
```

### Sonuçları dosyaya kaydetme
```bash
subfinder -d hedefsite.com -silent -o subdomains.txt
```

### Toplu alan adı listesi
```bash
subfinder -dL hedefler.txt -o toplu_sonuclar.txt
```

### Tüm pasif kaynakları kullanma
```bash
subfinder -d hedefsite.com -all -o detayli_sonuc.txt
```

# 10. Sherlock

## Amaç
Bir kullanıcı adının farklı sosyal ağlarda ve web hizmetlerinde bulunup bulunmadığını araştırır.

## Temel kullanım
```bash
sherlock kullanici_adi
sherlock kullanici_adi -o sonuc.txt
sherlock kullanici_adi --site Twitter --site GitHub
sherlock kullanici_adi --tor
```

## Raporlama

### CSV çıktısı
```bash
sherlock kullanici_adi --csv
```

### Excel çıktısı
```bash
sherlock kullanici_adi --xlsx
```

### Birden fazla kullanıcı adını klasöre kaydetme
```bash
sherlock user1 user2 user3 -fo ./sonuclar/
```

## Filtreleme

### Yalnızca bulunan sonuçları gösterme
```bash
sherlock kullanici_adi --print-found
```

### Bulunamayan sonuçları da gösterme
```bash
sherlock kullanici_adi --print-all
```

### Yetişkin içerikli siteleri dahil etme
```bash
sherlock kullanici_adi --nsfw
```

## Tor ve vekil sunucu

### Her istek için yeni Tor devresi
```bash
sherlock kullanici_adi --unique-tor
```

### SOCKS5 vekil sunucusu
```bash
sherlock kullanici_adi -p socks5://127.0.0.1:9050
```

### Bulunan profilleri tarayıcıda açma
```bash
sherlock kullanici_adi --browse
```

# 34. MDK3

## Amaç
Kablosuz ağ güvenliği testlerinde kullanılan bir araçtır.

## Temel modlar

- `b` : Çok sayıda sahte erişim noktası yayımlama.
- `d` : Kimlik doğrulama iptali ile istemcilerin bağlantısını kesmeye yönelik test.
- `p` : ESSID/probing tabanlı testler.
- `a` : Kimlik doğrulama hizmet reddi testi.

## Örnekler
```bash
sudo mdk3 wlan0mon b
sudo mdk3 wlan0mon d -c 6
```

**Not:** Kablosuz bağlantı kesme ve hizmet reddi testleri yalnızca kendi laboratuvarında uygulanmalıdır.

# 40. Omnibus

## Amaç
Birden fazla OSINT, tehdit istihbaratı ve ağ sorgusunu tek bir arayüz üzerinden çalıştırmaya yardımcı olur.

## Başlatma
```bash
omnibus
omnibus -o
```

## Temel oturum komutları
```text
omnibus >> session new
omnibus >> set target 192.0.2.1
```

## Tehdit istihbaratı ve OSINT
```text
omnibus >> shodan ip 192.0.2.2
omnibus >> virustotal domain hedefsite.com
omnibus >> whois hedefsite.com
omnibus >> censys search hedefsite.com
omnibus >> hibp test@example.com
```

## Ağ analizi
```text
omnibus >> nmap -p 80,443 hedefsite.com
omnibus >> dnsresolve sub.hedefsite.com
omnibus >> geoip 192.0.2.3
```

**Harici servis notu:** Shodan, VirusTotal, Censys ve HIBP sorguları ilgili dış servislerin altyapılarına bağlıdır.
Kimlik doğrulama ve API ayarları kullanılan hizmete göre değişebilir.
