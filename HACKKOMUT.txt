[+] SECRETFINDER
--------------------------------------------------------------------------------
Açıklama: JavaScript dosyaları veya web sayfaları içerisindeki gizli hassas verileri,
API anahtarlarını, şifreleri ve gizli endpoint'leri (bağlantı noktalarını) bulmak için kullanılır.

Komut:
secretfinder -i file://$PWD/index-BhYj0Brp.js -o cli

Örnek Kullanım Komutları:

* Tek Bir URL Üzerindeki JS Dosyalarını Tarama ve Çıkarma:
secretfinder -i https://example.com -e

* Sonuçları HTML Formatında Dosyaya Kaydetme:
secretfinder -i https://example.com/dosya.js -o rapor.html

* Burp Suite ile Dışarı Aktarılan Dosyayı Analiz Etme:
secretfinder -i burp_raporu.xml -b

1. Kimlik Doğrulama Gerektiren Sayfaları Tarama:
   - Çerez (Cookie) Kullanarak Tarama (-c):
     Giriş yapılmış bir oturumun çerezlerini ekleyerek, sadece yetkili kullanıcıların
     erişebildiği JavaScript dosyalarındaki gizli verileri aramak için:
     secretfinder -i https://example.com/panel -e -c "session=EXAMPLE_SESSION_TOKEN"

   - Özel Başlıklar (Headers) Ekleme (-H):
     Özel bir Authorization başlığı veya User-Agent tanımlayarak tarama yapmak için:
     secretfinder -i https://example.com -e -H "Authorization: Bearer EXAMPLE_TOKEN\nUser-Agent: Mozilla/5.0"

2. Belirli Endpoint'leri Filtreleme ve Daraltma (-r):
   - Sadece API Rotalarını Listeleme:
     Bulunan yüzlerce URL arasından sadece /api/ ile başlayan gizli endpoint'leri süzmek için regex filtresi:
     secretfinder -i https://example.com -e -r "^/api/"

3. Dosya ve Klasör Odaklı Tarama (-i):
   - Yerel Bir JavaScript Dosyasını Analiz Etme:
     İnternete çıkmadan, bilgisayarında kayıtlı olan bir .js dosyasını doğrudan incelemek için:
     secretfinder -i /yol/dosya.js -o sonuc.html

   - Yerel Bir Klasördeki Tüm Dosyaları Tarama:
     Toplu halde indirdiğin bir web sitesi dizinindeki tüm JS dosyalarını taramak için:
     secretfinder -i /yol/klasor/ -o cikti.html

4. İstekleri Proxy Üzerinden Yönlendirme (-p):
   - Burp Suite veya OWASP ZAP'e Trafik Gönderme:
     Araç üzerinden yapılan istekleri bir proxy aracına yönlendirerek trafiği izlemek için:
     secretfinder -i https://example.com -e -p 127.0.0.1:8080

5. Belirli Kelimeleri Hariç Tutma veya Odaklanma (-g ve -n):
   - Belirli Kütüphaneleri (örn. jQuery, Bootstrap) Yoksayma (-g):
     İçinde belirli bir ifade geçen (örneğin popüler kütüphane isimleri) JS dosyalarını tarama dışı bırakmak için:
     secretfinder -i https://example.com -e -g "jquery;bootstrap;analytics"

   - Sadece Belirli İçeriklere Sahip Dosyaları İşleme (-n):
     İsmi veya yolu içinde belirli bir kelime geçen JS dosyalarına odaklanmak için:
     secretfinder -i https://example.com -e -n "app;main;bundle"

[+] SUBFINDER
--------------------------------------------------------------------------------
Açıklama: ProjectDiscovery tarafından Go dilinde geliştirilmiş güçlü bir subdomain
keşif (enumeration) aracıdır. Hedef bir alan adının arkasında gizli kalmış alt alan
adlarını arama motorları, sertifika şeffaflık logları (Certificate Transparency) ve
çeşitli OSINT kaynakları üzerinden tarayarak listeler. Pasif kaynak modelinde hedefe
aktif tarama yapmaz; ancak kullanılan dış kaynaklara sorgular gönderebilir. Bu nedenle
"hiç iz bırakmaz" şeklinde kesin bir ifade kullanılmamalıdır.

Önemli Parametreler:
-d, -domain : Taranacak hedef alan adını belirtir.
-dL, -list  : İçerisinde birden fazla hedef olan metin dosyasını toplu taramak için kullanılır.
-s, -sources: Sadece belirli kaynakları kullanarak arama yapmayı sağlar.
-all        : Tüm pasif kaynakları devreye sokar.
-o, -output : Bulunan alt alan adlarını bir dosyaya kaydeder.
-silent     : Ekranda sadece bulunan subdomain'leri alt alta listeler.

Detaylı Örnek Kullanım Komutları:
* Temel Bir Alan Adı Taraması Yapma:
  subfinder -d hedefsite.com

* Sonuçları Bir Dosyaya Kaydetme ve Sessiz Mod (-silent):
  subfinder -d hedefsite.com -silent -o subdomains.txt

* Toplu Hedef Taraması Yapma (-dL):
  subfinder -dL hedefler.txt -o toplu_sonuclar.txt

* Tüm Kaynakları Kullanarak Derinlemesine Tarama:
  subfinder -d hedefsite.com -all -o detayli_sonuc.txt

[+] SHERLOCK
--------------------------------------------------------------------------------
Açıklama: Belirttiğin bir kullanıcı adını yüzlerce farklı sosyal medya platformunda,
forumda ve web sitesinde aynı anda arar. Hangi sitelerde o kullanıcı adına ait bir
profil olduğunu hızlıca raporlar.

sherlock kullanici_adi
sherlock kullanici_adi -o sonuc.txt
sherlock kullanici_adi --site Twitter --site GitHub
sherlock kullanici_adi --tor

1. Raporlama ve Dosya Formatları:
   - Sonuçları CSV Formatında Kaydetme:
     sherlock kullanici_adi --csv

   - Sonuçları Modern Excel (.xlsx) Formatına Aktarma:
     sherlock kullanici_adi --xlsx

   - Birden Fazla Kullanıcı Adı İçin Klasörlü Raporlama (-fo):
     sherlock user1 user2 user3 -fo ./sonuclar/

2. Filtreleme ve Site Kısıtlamaları:
   - Yalnızca Bulunan Sonuçları Konsola Yazdırma (--print-found):
     sherlock kullanici_adi --print-found

   - Bulunamayan (Olumsuz) Sonuçları da Gösterme (--print-all):
     sherlock kullanici_adi --print-all

   - NSFW (Yetişkin İçerikli) Siteleri Taramaya Dahil Etme (--nsfw):
     sherlock kullanici_adi --nsfw

3. Gizlilik, Proxy ve Tor Kullanımı:
   - Her İstek İçin Yeni Tor Devresi Kullanma (--unique-tor):
     sherlock kullanici_adi --unique-tor

   - Socks5 Proxy Üzerinden Trafiği Yönlendirme (-p):
     sherlock kullanici_adi -p socks5://127.0.0.1:9050

4. Ekstra Kolaylıklar:
   - Bulunan Tüm Profilleri Tarayıcıda Otomatik Açma (-b):
     sherlock kullanici_adi --browse

[+] MDK3
--------------------------------------------------------------------------------
Açıklama: Wi-Fi protokolündeki zafiyetleri istismar eden kablosuz ağ test aracı.
Modlar:
b (Beacon Flood Mode): Binlerce sahte Wi-Fi ağı yayar.
d (Deauthentication Amok Mode): Cihazları hedef ağdan koparır.
p (Probing & ESSID Bruteforce): Gizli SSID'leri kaba kuvvetle arar.
a (Authentication DoS): Aşırı miktarda kimlik doğrulama isteği gönderir.

sudo mdk3 wlan0mon b
sudo mdk3 wlan0mon d -c 6

[+] THEHARVESTER
--------------------------------------------------------------------------------
Parametreler:
-d, --domain   : Hedef alan adı.
-b, --source   : Veri kaynağı (google, github, crtsh, all vb.).
-l, --limit    : Sonuç sınırı.
-s, --shodan   : Shodan entegrasyonu.
-c, --dns-brute: DNS brute-force taraması.
-f, --filename : XML/JSON dosyaya kaydetme.
-t, --take-over: Subdomain takeover kontrolü.

Komutlar:
* Crt.sh Kaynağından Tarama:
  theHarvester -d hedefsite.com -b crtsh

* Tüm Kaynaklar ve Dosyaya Kaydetme:
  theHarvester -d hedefsite.com -b all -f sonuc_raporu

* DNS Brute-Force ve Shodan Entegre Tarama:
  theHarvester -d hedefsite.com -b google,virustotal -c -s


[+] TORCTL
--------------------------------------------------------------------------------
Komutlar:
start   : Tüm trafiği Tor ağına yönlendirir.
stop    : Normal internete döndürür.
status  : Mevcut durumu gösterir.
restart : Servisi ve kuralları yeniden başlatır.
ip      : Dışarıdan görünen IP adresini sorgular.
chngid  : Yeni bir Tor IP adresi alır.
chngmac : MAC adreslerini değiştirir.
rvmac   : Orijinal MAC adreslerine döndürür.

Kullanım Senaryosu:
torctl start
torctl ip
torctl chngid
torctl stop

[+] WIFIJAMMER
--------------------------------------------------------------------------------
Parametreler:
-i INTERFACE      : Ağ kartı (wlan0mon).
-c CHANNEL        : Belirli kanal.
-a [ACCESSPOINT]  : Özel hedef MAC/SSID.
-s [SKIP]         : Saldırı dışı bırakılacak MAC.
-d, --directedonly: Doğrudan istemci eşleşmelerine odaklanır.
--world           : 13 kanalı taramaya dahil eder.

Komutlar:
* Otomatik Modda Başlatma:
  sudo wifijammer

* Belirli Bir Ağı Hedef Alma:
  sudo wifijammer -a AA:BB:CC:DD:EE:FF

* Belirli Kanalda Dünya Standardı Tarama:
  sudo wifijammer -c 6 --world

* Kendi Cihazını Hariç Tutma (--skip):
  sudo wifijammer -s 11:22:33:44:55:66
